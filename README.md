    # 🐍 Minha Evolução em Lógica de Programação

Bem-vindo ao meu primeiro repositório!

Este projeto foi criado para registrar minha **evolução no aprendizado de lógica de programação**, começando pelos conceitos mais básicos e avançando gradualmente para desafios mais complexos.

A ideia é manter aqui uma espécie de **linha do tempo do meu aprendizado**, mostrando não apenas os códigos que desenvolvi, mas também os problemas que resolvi, os conceitos que aprendi e a evolução do meu raciocínio lógico.

# 📚 Conteúdo

## 🟢 01 — Fundamentos

Primeiros conceitos de programação.

* Variáveis
* Tipos de dados
* Entrada de dados
* Saída de dados
* Operadores
* Conversão de tipos

---

## 🟡 02 — Estruturas Condicionais

Aprendendo a fazer o programa tomar decisões com base em determinadas condições.

* `if`
* `elif`
* `else`
* Operadores relacionais
* Operadores lógicos

---

## 🟠 03 — Estruturas de Repetição

Aprendendo a executar determinadas instruções várias vezes.

* `for`
* `while`
* Contadores
* Acumuladores

---

## 🔵 04 — Estruturas de Dados

Explorando diferentes formas de armazenar e manipular informações.

* Listas
* Tuplas
* Dicionários
* Manipulação de dados

## 🔴 05 — Desafios

Exercícios que combinam diferentes conceitos para desenvolver cada vez mais o raciocínio lógico.

# 📝 Como estou organizando os exercícios

Sempre que possível, cada atividade seguirá esta estrutura:

### ❓ Pergunta

O problema que precisa ser resolvido.

### 🧠 Raciocínio

Como pensei para chegar à solução.

### 💻 Código

A implementação da solução.

### ▶️ Resultado

### 📚 O que aprendi

Um breve registro do conceito ou conhecimento adquirido.
